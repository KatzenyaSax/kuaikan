# P6 前端视觉翻新（Apple 风格）

> 状态：方案已定，执行中。落地事实回写到 `docs/project.md`「视觉与信息架构」一节。

## 1. 总方向：混合式

| 区域 | 风格 | 要点 |
|---|---|---|
| 未登录首页 hero、社群概览 hero | **营销页风** | 超大展示字（clamp 40→64px）、紧字距（-0.02em ~ -0.03em）、居中排版、深浅色带交替（`#000`/`#1d1d1f` 深带 + `#f5f5f7` 浅带）、主次两个胶囊按钮（实心蓝 + 文字链 `›`） |
| 信息流、帖子详情、评论、我的、用户主页、热榜、关注、发帖、登录注册 | **产品页风** | 毛玻璃顶栏、大标题 + 分组列表（inset grouped，`#f5f5f7` 底 + 白色圆角分组）、高密度但留白充足、hairline 分隔 |
| `/test` 诊断台 | 不动 | 仪表盘，不是产品页 |

## 2. 设计令牌（仍集中在 `web/src/styles/index.css`）

**字号仍是 7 档**（只改数值，不加第 8 档）：

| 档 | 旧 | 新 |
|---|---|---|
| caption | 11 | 12 |
| aux | 13 | 14 |
| body | 15 | 15 |
| read | 17 | 17 |
| sub | 20 | 21 |
| title | 28 | 32 |
| display | 40 | `clamp(40px, 6vw, 64px)`，行高 1.08，字重 700，字距 -0.025em |

- 标题字距统一收紧（title -0.015em，sub -0.01em）；中文正文行高保持 1.75~1.8。
- 颜色：前景 `#1d1d1f`（Apple 正文色，替代 `#0a0a0a`）；次要 `#6e6e73`；更弱 `#86868b`；页面浅底 `#f5f5f7`；强调蓝 `#0071e3`（hover `#0077ed`），**仍只用于交互态**。新增深带 `--color-ink: #000` / `--color-ink-2: #1d1d1f` 与其上文字 `#f5f5f7` / `#a1a1a6`。
- 圆角：sm 8 / md 12 / lg 18 / xl 28 / pill。
- 阴影维持 3 档；分组卡片不用阴影，靠浅底反衬。
- 动效：保留 3 档时长 + 1 条缓动（`cubic-bezier(0.28, 0.11, 0.32, 1)`，Apple 常用）；hero 只做进入时 opacity+translateY 渐显，**必须尊重 `prefers-reduced-motion`**。不引入动画库。

## 3. 布局外壳

- **顶栏**：高 48px（`--topbar-h` 同步改），`backdrop-filter: saturate(180%) blur(20px)` + `rgba(255,255,255,0.72)`，底部 hairline；导航文字 aux 档、`#1d1d1f` 80% 透明度，hover 100%。信息架构不变（首页/社群/关注/热榜/搜索 + 消息 + 头像）。
- **窄屏底部 tab**：同样毛玻璃；五个主导航不变。
- **内容容器**：产品页统一 `max-w-[980px]`（Apple 标准栏宽），阅读正文 680px；营销色带全宽，内部 980px。
- **页面大标题**：产品页顶部「大标题 + 一行副标题」，title 档、左对齐。
- 社群双栏布局保留（左列表 + 右正文），左栏改为分组列表风格。

## 4. 未登录首页（不新增路由）

`/` 在 **未登录** 时顶部插入营销 hero，登录后为紧凑版（只留页面大标题）：

1. 浅底 hero：display 大标题 + sub 副标题 + 「免费注册」实心胶囊 + 「先逛逛 ›」文字链（锚点滚到下方列表）。
2. 深色色带：一句产品主张 + **只用已有接口返回的真实数据**（例如已加载的社群数）——**不允许编造数字**，没有数据就不显示数字。
3. 下方保留现有「全部社群」「最新帖子」两区块，改为产品页风格。

## 5. 硬约束

1. **不改行为**：路由、接口调用、状态管理、文案语义（可润色措辞）不变；不改 `contract/`、后端、生成类型。
2. **`data-testid` 一个都不许删、不许改名**，被测元素的可见性/可点击性保持（e2e 依赖它们）。结构调整时把 testid 跟着搬到等价元素上。
3. 不新增 npm 依赖；不引入外部字体/图片 CDN（系统字体栈已含 SF Pro / PingFang）。
4. 遵守既有坑：不用 `text-background`；自定义字号与 `text-white` 同用时注意 twMerge（见 `project.md`）。
5. Markdown 渲染仍禁用 `rehype-raw`。
6. 按 `AGENTS.md`：禁止单测；每步跑 T0；动了 testid 相关渲染补 T2（`--layer l3`）；UI 改动不跑全量 verify。
